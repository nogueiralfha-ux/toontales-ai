# Roadmap do Projeto: Todo List em React

Este documento descreve as fases planejadas para o desenvolvimento do aplicativo Todo List.

## Fases do Projeto

### Fase 1: Setup do Ambiente e Estrutura Inicial
- [ ] Configuração do projeto com React + Vite + TypeScript.
- [ ] Integração do Tailwind CSS e configuração de tema básico.
- [ ] Estruturação inicial de pastas (components, context, hooks, types).

### Fase 2: Componentes Core e Layout
- [ ] Criação do layout principal (Header, Footer, Container).
- [ ] Componente `TodoInput` para criação de novas tarefas.
- [ ] Componente `TodoList` e `TodoItem` para renderização das tarefas.
- [ ] Componente de filtros (Todas, Ativas, Completadas).

### Fase 3: Gerenciamento de Estado e Persistência
- [ ] Implementação do React Context (`TodoContext`) ou Custom Hooks para estado global.
- [ ] Integração do LocalStorage para persistência de dados.
- [ ] Funcionalidades de CRUD básico: adicionar, alternar status de conclusão e remover tarefas.

### Fase 4: Recursos Avançados
- [ ] Edição de tarefas existentes em modo inline.
- [ ] Categorias ou tags para tarefas.
- [ ] Níveis de prioridade (Baixa, Média, Alta) com indicadores visuais.
- [ ] Ordenação e busca de tarefas.

### Fase 5: UI/UX, Acessibilidade e Ajustes Finais
- [ ] Animações de transição com Framer Motion.
- [ ] Ajustes de acessibilidade (atributos ARIA, navegação por teclado).
- [ ] Testes unitários básicos para hooks de lógica.
- [ ] Documentação de uso final.
